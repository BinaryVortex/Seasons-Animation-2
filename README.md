# Seasons Animation 2

A beautiful animated representation of the four seasons using pure HTML and CSS.

## Features

- Interactive season selection with radio buttons
- Smooth CSS animations for each season:
  - **Spring**: Flowers blooming and colorful scenery
  - **Summer**: Bright sun and vibrant atmosphere
  - **Autumn**: Falling leaves and warm colors
  - **Winter**: Snow falling and cool tones

## Technologies Used

- HTML5
- CSS3 (Animations, Transitions, and Keyframes)

## How to View

1. Clone the repository or download the files.
2. Open `index.html` in any modern web browser.
3. Click on the season buttons to switch animations.
